# Portfolio Architecture

## Overview

This portfolio is built using a modern React architecture with reusable components,
centralized data management, and a scalable folder structure.

## Technology Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Folder Structure

src/
├── assets/
├── components/
│   ├── hero/
│   ├── ui/
│   └── ...
├── data/
├── sections/
├── types/
└── App.tsx

## Architecture Principles

- Component-first design
- Data-driven UI
- Separation of content and presentation
- Reusable UI components
- Strong typing with TypeScript

## Rendering Flow

App
│
├── Hero
├── Trusted Technologies
├── About
├── Core Expertise
├── Experience
├── Leadership Impact
├── Professional Growth
└── Contact

## Performance

- Vite Production Build
- Code Splitting
- Lazy Loading
- Optimized WebP Assets
